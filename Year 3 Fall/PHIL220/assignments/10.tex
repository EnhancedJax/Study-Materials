    \item For $\forall x\left(F(x)\to G(x)\right)\therefore \exists x\left(F(x)\land G(x)\right)$, consider domain $D=\{a\}$ where $F(a)=F, G(a)=F$.
          \begin{itemize}
              \item $\models \forall x\left(F(x)\to G(x)\right)$ as $F(a)\to G(a)$ is true.
              \item $\not\models \exists x\left(F(x)\land G(x)\right)$ as $F(a)\land G(a)$ is false.
              \item $\therefore \not\models \forall x\left(F(x)\to G(x)\right)\to \exists x\left(F(x)\land G(x)\right)$
          \end{itemize}
          Hence, argument is not a tautology. By soundness of proof system, there is no proof for the statement.

              \item $\therefore \not\models \forall xF(x)\vee\forall x\neg F(x)$
          \end{itemize}
          Hence, argument is not a tautology. By soundness of proof system, there is no proof for the statement.
