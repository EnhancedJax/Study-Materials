\begin{enumerate}
    \item For domain $D={a}$, the statement $\exists x \neg(A(x) \lor B(x))$ not a validity. For this only element $a$, if we let $A(a)$ and $B(a)$ be true, then $\neg(A(a) \lor B(a))$ is false, so the existential statement is false.
    \item For domain $D={d}$, intepret $a=d,b=d,F=\emptyset,G=\{d,d\}$, the statement $\forall x\big(F(x)\to G(x,a)\big),\quad G(b,a)\quad\therefore F(b)$ has a counterexample. Here, $F(d)$ is false, so the premise $\forall x\big(F(x)\to G(x,a)\big)$ is true (since the antecedent is false). Also, $G(b,a)$ is true since $G(d,d)$ is in the interpretation. However, the conclusion $F(b)$ is false since $F(d)$ is false. Thus, the argument is not an entailment.
    \item For $\neg\exists x\big(C(x)\wedge A(x)\big),\quad\neg C(m)\quad\therefore\quad A(m)$, intepret $D={d},m=d,C=\emptyset, A=\emptyset$.
